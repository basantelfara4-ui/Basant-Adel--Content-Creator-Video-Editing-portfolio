# Basant Adel Portfolio

Static portfolio website. No build step and no external services are needed.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (for example `portfolio`).
2. Upload everything in this folder to the repository root:
   `index.html`, `assets/`, `README.md`.
3. Go to Settings > Pages, choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. The site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Structure
- `index.html`: main page (all sections).
- `assets/css/style.css`: all styles (Cairo font loads from Google Fonts).
- `assets/js/main.js`: navigation, filters, case study and modal behaviour.
- `assets/images/`: logos, design images and reel thumbnails.
